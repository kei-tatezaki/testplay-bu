安全への取り組み

絶対に安全なサイトはありません。だからテストプレイ部では、入られにくくする、入られても被害を小さくする、すぐ止めて元に戻せる、の3つで守っています。

入られにくくする

  • パスワードを預かりません。ログインは Google・Discord のアカウントか、メールに届くログイン用のリンクで行います。テストプレイ部から、あなたのパスワードがもれることはありません
  • 通信はすべて暗号化しています（HTTPS）
  • 人のデータは、仕組みとして読めません。データベースの1行1行に「だれが読めるか」の決まりをつけています（行レベルセキュリティ）。ほかの人の履歴やPCで遊ぶリストは、本人しか読めません。運営用の操作は、毎回サーバー側で運営かどうかを確かめます
  • 読み込んでよい場所を決めています。このサイトのページは、決められた場所（このサイトと、データを置いている Supabase など）以外からはスクリプトを読み込まず、データも送りません（Content-Security-Policy）
  • 使っている部品は、このサイトの中に置いて版を固定しています。外の配布元が書きかえられても、その影響を受けません
  • ほかの人のゲームは、このサイトと分けて動かします。ほかの人のゲームは itch.io などの別の場所に置いてもらい、サイトの中で遊ぶときも、できることを絞った枠（sandbox）で開きます
  • 書かれた文は、ただの文字として表示します。感想やプロフィールにプログラムを書かれても動きません。リンクは https:// のものだけ出します
  • 秘密の鍵は、サイトのコードに入れていません。AIやDiscordにつなぐ鍵は、サーバー側の金庫（Supabase・GitHub のシークレット）にだけ置いています

入られても被害を小さくする

  • 大事な情報を、そもそも持っていません。パスワード・住所・電話番号・お金の情報は集めていません。集めているものは集める情報と使い道にすべて書いてあります
  • 送れる回数に上限があります。感想・いいね・応募などは、1時間あたりの回数を、端末・アカウント・ネットワークごとに数えて、多すぎると止めます。AIコーチは1人1日30回までです
  • 応募された動画は、非公開の置き場に入ります。運営だけが、10分で切れるリンクで確かめます

すぐ止めて、元に戻せる

  • 緊急停止スイッチがあります。荒らしや乗っ取りに気づいたら、運営がボタン1つで、サイト全体の送信を止められます。止めている間も、遊ぶ・見るのはできます
  • 毎日バックアップを取ります。データベースを暗号化して、30日分を保管します（準備中）
  • サイトの変更は、すべて記録が残ります。サイトのコードは GitHub で公開していて、だれが・いつ・何を変えたかが残り、いつでも前の状態に戻せます

もし何かあったら

情報がもれたなど、使っている人に関わる問題が分かったときは、分かったことと、あなたがすべきことを、サイトとDiscordですぐにお知らせします。

弱いところを見つけたら

サイトの安全上の問題に気づいたら、tatekei170+tpb@gmail.com に知らせてください。直すまでは、ほかの人に公開しないでください。

  • 善意で知らせてくれた人を、責めたり訴えたりはしません
  • 確かめるときは、自分のアカウントだけを使い、ほかの人のデータを見たり変えたりしないでください。サイトを重くする試し方もやめてください
  • 直したら、知らせてくれた人に連絡します（希望すれば、お礼として名前をこのページに載せます）
