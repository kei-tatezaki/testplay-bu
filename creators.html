説明するより、
遊んでもらおう。

小さく遊べる版を出すだけで、遊んだ人の数・感想・直した記録がぜんぶ1ページに残る作品ページができます。

最初の1本は投稿無料はじめての応募は、ポイントなしで送れます。2本目からは30ポイント（感想を書くとたまります）。
必要なのは3つだけ作品名 ・ 遊べるURL ・ 一言（何をするゲーム？）完成していなくても大丈夫。最初の1面だけ、テスト部屋だけでもOKです。

載るまでの流れ

  1. 応募フォームに3つを書いて送る
    まだURLがない人は、遊べるURLの作り方へ。
  2. 運営が遊んでから、作品ページを作る
    運営がひとりで見ているので、1週間ほどかかることがあります。1週間たっても載らなければ、Discordで声をかけてね。載ったらDiscordで紹介します。
  3. 数字と感想を見る
    開発者ページで、遊んだ人の数・遊んだ時間・感想が見られます。

  • 遊べる作品ページ：遊ぶボタン・動画・確かめたいことが1ページに。URLを1本貼るだけでポートフォリオになります

遊べるURLの作り方タップでひらく

「ダウンロードして遊ぶ」ではなく、ブラウザで開いてすぐ遊べるURLがおすすめです。遊ぶ人の数がまるで変わります。どれも無料です。

unityroomUnityで作った人に。日本語でかんたん
  1. Unityで「WebGL」向けにビルドする（圧縮は Gzip にする）
  2. unityroomに登録して「ゲームを登録」
  3. ビルドでできた4つのファイルをアップロード
  4. 公開して、ゲームのページのURLをコピー
itch.ioUnity・Godot・GameMaker・ティラノなど何でも
  1. Web（HTML5）向けに書き出す
  2. 書き出したフォルダをZIPにする（index.html がいちばん上に来るように）
  3. itch.ioで「Upload new project」→ 種類を「HTML」にしてZIPをアップロード
  4. 「This file will be played in the browser」にチェック
  5. 公開（Public）にして、ページのURLをコピー
GitHub PagesJavaScriptで作った人、GitHubを使っている人に
  1. index.html が入ったフォルダを、公開リポジトリにプッシュ
  2. リポジトリの Settings → Pages を開く
  3. 「Deploy from a branch」で main を選んで保存
  4. 1〜2分待つと https://ユーザー名.github.io/リポジトリ名/ で遊べる
そのほかすでに置いてある人はそのURLでOK
  1. ふりーむ！・PLiCy・自分のサイトなど、ブラウザで遊べればどこでもOK
  2. RPGツクールやティラノは「ブラウザ向け」に書き出す
  3. Scratchは作品ページのURLをそのまま

うまくいかないとき

  • 開いても真っ白：ZIPのいちばん上に index.html があるか確かめる（フォルダの中にフォルダが入っていないか）
  • Unityで読み込みが止まる：Player Settings の「Compression Format」を Gzip か Disabled にしてビルドし直す
  • 重い・長い：最初の1面だけ、テスト部屋だけの「小さい版」にする。200MB以下、読み込み30秒以内がめやす
  • スマホで動くかわからない：わからなければ「PCのみ」で出してOK。あとから変えられます
  • URLがまだない：Discordで聞いてくれれば、運営がいっしょに見ます
ポイントのしくみタップでひらく

テストプレイ部は、遊んで感想を送り合う場所です。ポイントは、ほかの人の作品に感想を送るとたまり、作品を応募するときに使います。

最初の1本は無料：はじめての応募は、ポイントなしで送れます。ポイントがいるのは、2本目からです。見送りになったときは、無料がもう一度使えます。

ためる

  • ログインして、遊んだ作品に、一言を40字以上（空白は数えません）で書いた感想を送ると、ポイントがつきます。
  • 感想が少ない作品ほど多く：0〜2件の作品は +10pt、3〜9件は +5pt、10件以上は +2pt。
  • 自分の作品、遊んでいない作品、同じ言葉のくり返しの感想には、つきません（感想は送れます）。
  • もらえるのは、1日 50pt までです。運営が感想を非表示にしたら、その分は取り消されます（表示に戻れば返ります）。

つかう

  • 作品の応募：30pt（足りないときは、応募フォームにそう出ます）。見送りになったら返します。
  • 載っている作品の直しの依頼：ポイントはいりません。

数字（40字・50pt・30pt など）は、様子を見て運営が変えることがあります。いまのポイントはマイページで見られます。

よくある質問タップでひらく

お金はかかる？

かかりません。載せるのも、遊ぶのも無料です。

作品はだれのもの？

作った人のものです。テストプレイ部は、遊べるURLへの入口と感想を集める場所を用意するだけです。

あとで直したり、消したりできる？

できます。ログインして、自分の作品の「⋮」→「直したいところを運営に送る」から送るか、Discordで運営に言ってください。

どんな感想が届く？

「もう一回遊びたい？」「どこまで遊んだ？」などの選ぶ質問と、一言です。だれが書いたかは作った人には見えません。遊んでから書いてね。遊ばずに書いた、ふざけた感想や、作品をけなすだけの感想は運営が消します。作品ページの例で見え方を確かめられます。

プロフィールは作れる？

マイページで、名前・アイコン・ひとこと・X や itch.io などのリンクを書けます。例：運営のプロフィール

だれが運営しているの？

たざろす（ゲーム企画を目指す学生。テストプレイ部の発起人）です。連絡先はDiscord。応募のこと、直したいところ、消してほしいときなど、なんでも声をかけてください。

年齢制限のある作品についてタップでひらく

ホラーや暴力表現のある作品（R15）、18歳以上向けの作品（R18）も載せられます。載せるときに、どちらにあたるかを教えてください。年齢の確認は自己申告です。高校生も来る場所なので、R18作品は表紙で隠し、作品の中身は外のサイトに置いてもらいます。

  • R15：作品に「R15」の印がつきます
  • R18：見る人が18歳以上だと確認するまで、作品は表紙で隠れます。作品の画像や動画はこのサイトには置かず、共通の表紙を使います。ゲーム本体は、年齢制限のある作品を置けるサイトに置いてください
  • R18の作品は、Discordの新作通知と毎日のおすすめには流れません
  • 未成年を性的に描いたもの、実在の人物を性的に描いたものは載せられません
