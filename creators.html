作品を載せたい人へ

説明するより、
遊んでもらおう。

小さく遊べる版を出すだけで、作品ページができます。遊んだ人の数も、もらった感想も、それを受けて直した記録も、ぜんぶ1ページに残ります。

作品を応募する遊べるURLの作り方

載せるまでの流れ

  1. 遊べるURLを作る
    ブラウザで開いてすぐ遊べるURLを用意します。作り方は下の「遊べるURLの作り方」へ。
  2. URLを運営にわたす
    応募フォームに、作品名・URL・一言の3つを書いて送るだけ。Discordで運営に声をかけてもOK。
  3. 運営が遊んで、作品ページを作る
    運営がかならず遊んでから載せます。載ったらDiscordの「新作とおすすめ」に流れます。
  4. 数字と感想を見る
    ログインすると、開発者ページで遊んだ人の数・遊んだ時間・感想が見られます。マイページでプロフィールも作れます。

こんな人に使ってほしい

  • ゲームは作ったけど、ポートフォリオに載せるにはちょっと薄いと感じている人
  • 機能をひとつずつ文章で説明するのがダルい人
  • 作ったゲームが、誰にも遊ばれないまま眠っている人
  • 面接で「ユーザーの声を聞いて改善した経験」を話せるようにしたい人

載せるとできること

  • 遊べる作品ページ：遊ぶボタン、動画、あなたが確かめたいことが1ページにまとまる。URLを1本貼るだけでポートフォリオになる
  • 数字が自動で並ぶ：遊んだ人の数、「また遊びたい」の割合、感想の数
  • 直した記録が残る：感想を読んで直したら「感想でアップデート」に、いつ・どんな声で・何を直したかが残る
  • 説明は全部書かなくていい：遊んでもらえば伝わる

例：いろタッチ30の作品ページ（もらった感想で直した記録つき）

完成していなくても大丈夫

テスト部屋だけ、最初の1面だけ、チュートリアルだけでも、立派な作品ページになります。重いゲームは、遊ぶ部分だけを切り出した「小さい版」にしてください。

載せるのに必要なもの

  • ブラウザで遊べるURL（容量は200MB以下がおすすめ）
  • 一言（何をするゲームか）
  • 画像1枚（あれば5〜10秒の動画も）
  • 対応端末（PCのみ／スマホのみ／PC・スマホ）
  • あなたが確かめたいこと（操作感・楽しさ・チュートリアルなど）

遊べるURLの作り方

「ダウンロードして遊ぶ」ではなく、ブラウザで開いてすぐ遊べるURLがおすすめです。遊ぶ人の数がまるで変わります。どれも無料です。

unityroomUnityで作った人に。日本語でかんたん
  1. Unityで「WebGL」向けにビルドする（圧縮は Gzip にする）
  2. unityroomに登録して「ゲームを登録」
  3. ビルドでできた4つのファイルをアップロード
  4. 公開して、ゲームのページのURLをコピー
itch.ioUnity・Godot・GameMaker・ティラノなど何でも
  1. Web（HTML5）向けに書き出す
  2. 書き出したフォルダをZIPにする（index.html がいちばん上に来るように）
  3. itch.ioで「Upload new project」→ 種類を「HTML」にしてZIPをアップロード
  4. 「This file will be played in the browser」にチェック
  5. 公開（Public）にして、ページのURLをコピー
GitHub PagesJavaScriptで作った人、GitHubを使っている人に
  1. index.html が入ったフォルダを、公開リポジトリにプッシュ
  2. リポジトリの Settings → Pages を開く
  3. 「Deploy from a branch」で main を選んで保存
  4. 1〜2分待つと https://ユーザー名.github.io/リポジトリ名/ で遊べる
そのほかすでに置いてある人はそのURLでOK
  1. ふりーむ！・PLiCy・ゲームアツマール系・自分のサイトなど、ブラウザで遊べればどこでもOK
  2. RPGツクールやティラノは「ブラウザ向け」に書き出す
  3. Scratchは作品ページのURLをそのまま

うまくいかないとき

  • 開いても真っ白：ZIPのいちばん上に index.html があるか確かめる（フォルダの中にフォルダが入っていないか）
  • Unityで読み込みが止まる：Player Settings の「Compression Format」を Gzip か Disabled にしてビルドし直す
  • 重い・長い：最初の1面だけ、テスト部屋だけの「小さい版」にする。200MB以下、読み込み30秒以内がめやす
  • スマホで動くかわからない：わからなければ「PCのみ」で出してOK。あとから変えられます
  • URLがまだない：Discordで聞いてくれれば、運営がいっしょに見ます

URLの渡し方

URLができたら、応募フォームに貼って送ってください。Discordの人は、運営にURLを送るだけでも大丈夫です。

よくある質問

お金はかかる？

かかりません。載せるのも、遊ぶのも無料です。

作品はだれのもの？

作った人のものです。テストプレイ部は、遊べるURLへの入口と感想を集める場所を用意するだけです。

あとで直したり、消したりできる？

できます。ログインして、自分の作品の「⋮」→「直したいところを運営に送る」から送るか、Discordで運営に言ってください。

どんな感想が届く？

「もう一回遊びたい？」「どこまで遊んだ？」などの選ぶ質問と、一言です。だれが書いたかは作った人には見えません。作品ページの例で、じっさいの見え方を確かめられます。

プロフィールは作れる？

マイページで、名前・アイコン・ひとこと・X や itch.io などのリンクを書けます。作品のとなりのアイコンから、あなたのプロフィールと作品の一覧に飛べるようになります。例：運営のプロフィール

年齢制限のある作品について

ホラーや暴力表現のある作品（R15）、18歳以上向けの作品（R18）も載せられます。載せるときに、どちらにあたるかを教えてください。

  • R15：作品に「R15」の印がつきます
  • R18：見る人が18歳以上だと確認するまで、作品は表紙で隠れます。作品の画像や動画はこのサイトには置かず、共通の表紙を使います。ゲーム本体は、年齢制限のある作品を置けるサイトに置いてください
  • R18の作品は、Discordの新作通知と毎日のおすすめには流れません
  • 未成年を性的に描いたもの、実在の人物を性的に描いたものは載せられません

運営の約束

載せた作品は、運営が必ず全部遊んで感想を書きます。感想は、遊んだ人がログインして送るものだけが届きます。作品をけなすだけの感想や、遊ばずに書いた感想は運営が消します。
