集める情報と使い道

テストプレイ部では、作品をよくするための数字と、荒らし対策のために、次の情報を集めています。広告のための追跡はしていません。

運営者と連絡先

運営者：舘崎 慶（たざろす。ゲーム企画を目指す学生。テストプレイ部の発起人）。連絡先はtatekei170+tpb@gmail.com、またはDiscordです。サイトの使い方の決まりは利用規約、守り方は安全への取り組みにあります。

集めるもの

  • 端末ごとのID：ブラウザに保存するランダムな文字列です。名前やメールアドレスとはつながっていません
  • サイトを開いた日：サイトを開いた日（1日1回、端末のIDと日付だけ）。運営が、何人が来たかを数えるために使います
  • 遊んだ記録：「遊ぶ」「いいね」「うーん」を押したこと（「うーん」は選んだ理由も）、遊んだ時間、PCかスマホか、時間帯
  • いいねと履歴：いいねした作品と、見た・遊んだ作品（日時、遊んだ秒数）。この端末のブラウザに残し、ログインしているときは、あなたのアカウントにも保存します（ログインしたとき、この端末の記録をアカウントに引き継ぎます）。履歴は新しいものから最大500件までです
  • フォロー：だれが、だれをフォローしているか（日時つき）。フォローするには、プロフィールが必要です。1人が1000人までで、短い間に何度も押すと、いったん止まります
  • 第一印象：ショートの動画を見て「遊んでみたい？」に答えた3段階と、100字までのひとこと（遊んでいなくても送れます）。端末のID、ログインしているときはアカウントと結びつきますが、作者や公開の画面には、人数とひとことだけが出て、だれが送ったかは出ません。同じ人が同じ作品に送れるのは1日1回です。ポイントやミッションには関係しません
  • PCで遊ぶリスト：スマホで「PCで遊ぶリストに入れる」にした作品。ログインしていないときはこの端末のブラウザにだけ残し、ログインしているときは、あなたのアカウントにも保存します（ログインしたとき、この端末の分を引き継ぎます）。本人だけが見られ、200本までです。PCで遊ぶと、リストから外れます
  • 感想：送った内容と、送ったアカウント（ログインした人のみ）
  • この端末に残すもの（アプリとして使うとき）：ホーム画面に追加して使えるよう、サイトの画面・CSS・JS・画像を、ブラウザの中（service worker のキャッシュ）に一時的に残します。ネットにつながらないときの表示と、読み込みを早くするためです。外のサーバーには送りません。ブラウザの設定で消せます。「先読みする」のオン・オフも、この端末の中だけに記録します
  • AIコーチ：ログインして感想シートの一言を書いていると、手を止めたときに自動で、その文・作品の名前と説明・作者が選んだ「ほしい感想の温度」と目標が、Anthropic の Claude API に送られ、言いかえの提案が返ってきます。運営のデータベースに残るのは、使った回数と時刻だけです（文は残しません）。Anthropic の決まりでは、API に送られたデータは、原則として AI の学習には使われません
  • 回数の数え表：荒らしや大量の送信を止めるため、感想・いいねなどを送ったとき、1時間ごとの回数を「端末のID」「アカウント」「ネットワークの指紋」ごとに数えます。ネットワークの指紋は、IPアドレスに秘密の文字列と日付をまぜて作った16文字で、IPアドレスそのものは保存しません。日付が変わると別の指紋になり、数え表は2日で消えます
  • ログインの情報：メールアドレス、またはDiscord・Googleのアカウントの名前とメールアドレス
  • プロフィール：自分で書いた名前・ID・ひとこと・リンク・アイコンの画像（作った人だけ。だれでも見られます）
  • 作品の応募：応募フォームに書いた内容と、送ったアカウント。3Dモデルのファイル（.glb / .vrm）は、運営だけが見られる場所に置きます
  • 3Dモデルの確認：運営がモデルを確かめるとき、ブラウザでモデルを開いて測った数字（ポリゴン数・テクスチャ・骨など）と、自動で撮った画像（正面・横・後ろなど6枚まで）、フォームに書いた用途・目的を、Anthropic の Claude API に送り、見立てをもらいます。モデルのファイルそのものは送りません。見立ては運営だけが見られる場所に、新しい5回分まで残します
  • 報告：「報告する」で送った内容と、端末ごとのID（ログインしていればアカウントも）

使い道

  • ショートの並び順（あなたに合いそうな作品を先に出すため）
  • 作った人に、作品の数字（遊んだ人の数・遊んだ時間・離れたところなど）と感想を届けるため
  • マイページの「いいね」「履歴」に出して、あとから見返せるようにするため
  • 荒らしや、ふざけた感想への対策（感想の非表示・送れなくする措置）のため

だれに見えるか

  • 作った人：自分の作品の合計の数字と、感想の本文。だれが書いたかは見えません
  • テスト結果カード：作者が「カードを作る」で開く公開ページ（result.html?g=作品ID）。遊んだ人数・遊んだ回数・遊んだ時間の真ん中・「もう一回遊びたい」と作者の質問の「はい」の割合・第一印象の割合・感想の件数・いいねの数・集計した期間が、URLを知っている人ならだれでも見られます。割合は、答えた人が5人になるまで出しません。作者が「カードに載せる」と選んだ感想（最大3件）は、先頭120字と日付だけが、名前・アカウント・端末のIDなしで載ります（選びなおし・外すのは作者がいつでもできます。非表示になった感想は出ません）。R18の作品、BANされた端末やアカウントの記録、作者自身の感想は含めません
  • 運営：上のすべて。感想を書いたアカウントの名前は、荒らし対策のためにだけ使います
  • みんな：作品ページの感想の本文と、遊んだ人の数などの合計。プロフィールに自分で書いたもの
  • いいね：自分だけが見られます。マイページで「いいねした作品を公開する」をオンにしたときだけ、公開プロフィールに出ます（最初はオフ。いつでもオフに戻せます）
  • 履歴：自分だけが見られます。公開されることはありません。運営向けの画面にも出しません
  • フォロー：だれが、だれをフォローしているかは、本人と相手のフォロー中・フォロワーの一覧に出ます（名前・ID・アイコン・ひとことだけ）。数も公開プロフィールに出ます。ログインしていない人にも見えます
  • 感想を書いた人のプロフィールが、感想の横に出ることはありません。報告は運営だけが見ます

保存する場所

Supabase（東京のサーバー）に保存しています。サイトはGitHub Pagesで公開しています。データが消えたときに戻せるよう、データベースのバックアップを、パスワードで暗号化して30日間だけ保管します（GitHub の中。暗号を解く鍵は運営だけが持っています）。

プロフィールの動画はYouTubeから読み込みます（押したときだけ）。

文字のデザイン（フォント）はGoogle Fontsから読み込みます。このとき、Googleにアクセス元の情報（IPアドレスなど）が送られます。

消してほしいとき

自分の感想やアカウントの情報を消してほしいときは、メールかDiscordで運営に連絡してください（バックアップの中の分も、30日で消えます）。ブラウザに保存されたIDや記録は、ブラウザのサイトデータを消すと消えます。

プロフィールとアイコンの画像は、マイページでいつでも自分で直せます。

いいねはマイページの「いいね」から1本ずつ外せます。履歴はマイページの「履歴」の「履歴を消す」で、まとめて消せます（このブラウザの記録も一緒に消えます）。フォローは、相手のプロフィールの「フォロー中」を押すと、いつでもやめられます。
